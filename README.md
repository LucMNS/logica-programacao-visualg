# 💻 Exercícios de Lógica de Programação - VisualG

Repositório contendo **86** resoluções de algoritmos desenvolvidos em pseudocódigo (Portugol) utilizando o **VisualG 3.0**, abrangendo exercícios práticos de lógica, estruturas condicionais e laços de repetição.

---

## 📁 Estrutura do Repositório

O projeto está organizado nas seguintes pastas:

```text
VisualG/
├── VisualG-Faccat/            # Resoluções dos exercícios da apostila Faccat
├── VisualG-Manzano/           # Resoluções dos exercícios da apostila Manzano
└── VisualG-OutrosProjetos/    # Algoritmos adicionais e exercícios complementares
```

> **Nota:** Os arquivos estão identificados pela numeração correspondente a cada exercício nas apostilas de referência.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Pseudocódigo (Portugol)
- **Ambiente de Execução:** [VisualG 3.0.7](https://visualg3.com.br/)

---

## 🚀 Como Executar os Arquivos

1. Baixe e instale o **VisualG 3.0** (ou utilize a versão portátil).
2. Baixe o arquivo `.ZIP` do repositório (no botão verde **Code > Download ZIP**) e extraia os arquivos no seu computador.
3. Abra o aplicativo do **VisualG**.
4. Pressione `F3` (ou acesse **Arquivo > Abrir**) e selecione o arquivo `.alg` desejado dentro da pasta correspondente.
5. Pressione `F9` (ou acesse **Executar > Rodar algoritmo**) para iniciar a execução no console.
